[ENGLISH INSTRUCTIONS]
1. How to Setup & Run on ANY PC:
   - Double-click "1-CLICK_SETUP_AND_RUN.bat"
   - It will automatically verify Python, set up dependencies, create desktop icons, and launch JARVIS!
2. Adding Your API Key:
   - When JARVIS opens for the first time, the "Stark Industries Neural Link Setup" window will appear.
   - Copy your Google Gemini API key (from https://aistudio.google.com/app/apikey).
   - Click the "PASTE" button inside the app.
   - Click "CONNECT & ACTIVATE JARVIS".
   - Your key is saved locally in config/api_keys.json (it is NEVER shared or uploaded).
3. Everyday Usage:
   - Just double-click the "JARVIS" icon on your Windows Desktop!
